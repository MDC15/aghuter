# Run relevant tests

**Workflow ID:** `tests.run`

1. Inspect project instructions and manifests to discover the actual test runner.
2. Map changed behavior to the smallest useful test set.
3. Explain the selected command and run it through the host agent terminal.
4. Capture exit status and summarize failures; broaden coverage only when justified.

## Completion report

- Outcome and scope
- Commands/tools used and why
- Checks: passed / failed / skipped / inconclusive
- Files changed (if any)
- Approval or follow-up required
