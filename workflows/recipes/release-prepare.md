# Prepare release readiness

**Workflow ID:** `release.prepare`

1. Inspect branch, worktree, version files, changelog, release docs, and CI state.
2. Discover documented build and validation commands.
3. Run appropriate local checks and list blockers.
4. Do not tag, push, publish, or deploy without explicit authorization for the exact target.

## Completion report

- Outcome and scope
- Commands/tools used and why
- Checks: passed / failed / skipped / inconclusive
- Files changed (if any)
- Approval or follow-up required
