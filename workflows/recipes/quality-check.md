# Run project quality checks

**Workflow ID:** `quality.check`

1. Discover configured lint, type-check, format-check, and build scripts.
2. Select checks relevant to the changed files.
3. Run separate checks when failure boundaries differ.
4. Report pass, fail, skipped, and inconclusive distinctly; do not install missing tools without approval.

## Completion report

- Outcome and scope
- Commands/tools used and why
- Checks: passed / failed / skipped / inconclusive
- Files changed (if any)
- Approval or follow-up required
