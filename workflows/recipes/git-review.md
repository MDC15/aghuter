# Review current Git changes

**Workflow ID:** `git.review`

1. Inspect branch and worktree status.
2. Read staged and unstaged diffs separately; inspect untracked filenames and relevant file contents.
3. Prioritize correctness, security, regressions, and missing tests.
4. Report only actionable findings with severity, path, and line; state when no findings were found.

## Completion report

- Outcome and scope
- Commands/tools used and why
- Checks: passed / failed / skipped / inconclusive
- Files changed (if any)
- Approval or follow-up required
