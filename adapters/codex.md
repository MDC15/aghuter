# Codex adapter

- Install at `.agents/skills/aghuter/` in a repository, or the user-level Codex skills directory supported by your installation.
- Invoke with `$aghuter` or let Codex select it from the task description.
- Use Codex-native terminal, file, and Git capabilities when available; do not wrap them in shell unnecessarily.
- Respect Codex approval/sandbox controls. This skill never grants additional permissions.
